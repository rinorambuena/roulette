# 🎡 Ruleta

A lightweight, zero-dependency roulette wheel that runs entirely in the browser.

## Features

- 2 to 12 participants
- Customizable participant names
- Two game modes: Simple and Elimination
- Quick bulk name loading via semicolon-separated input
- Randomized outcomes — no two spins are the same

## Demo

[Play it here](https://rinorambuena.github.io/roulette/)

## Getting Started

### Option 1 — Open locally

Just download `index.html` and open it in any browser. No install, no server needed.

### Option 2 — Clone and run

```bash
git clone https://github.com/rinorambuena/roulette.git
cd roulette
open index.html
```

## How to use

1. Set up participants in the config panel (or use bulk load)
2. Choose a game mode:
   - **Simple** — spin once, one participant is selected
   - **Elimination** — the wheel spins automatically, eliminating one participant at a time until only one remains
3. Press **Girar** and watch the wheel

## Built with

Plain HTML, CSS, and JavaScript — no frameworks, no libraries.
